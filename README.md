This project analyzes fitness and activity data collected from Fitbit users between March 2016 and May 2016. The dataset contains 18 CSV files tracking daily activity, steps, calories, heart rate, sleep, and intensity levels.
Dataset Source:
Downloaded from Kaggle: FitBit Fitness Tracker Data
Files Included:
        •       Daily activity, calories, steps, intensities
        •       Hourly calories, steps, intensities
        •       Minute-level calories, steps, intensities
        •       Heart rate, sleep, and weight data
Goals of Analysis:
        •       Understand daily movement patterns
        •       Identify relationships between activity and calorie burn
        •       Explore sleep and activity correlations
Tools Used:
        •       Python / Pandas
        •       Data visualization libraries
How to Use:
Download the dataset from Kaggle and place CSV files in the data folder before running any notebooks.
